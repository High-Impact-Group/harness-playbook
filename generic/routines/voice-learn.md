# voice-learn

Compare a draft you edited against the original, extract what changed and why, and save the lessons for future drafts.

I have edited a draft that you produced. Extract what I changed and why. Then save the lessons so future drafts improve.

## Step 1: Get both versions

Ask me for:
1. The original draft (or find it in the conversation history if it was produced this session)
2. The version I actually used, posted or sent

## Step 2: Extract corrections

Compare the two versions line by line. For each meaningful change, identify:
- **What you wrote:** the original phrasing
- **What I changed it to:** my version
- **Why:** infer the lesson (tone, specificity, length, structure, word choice, unneeded hedging and so on)

Ignore trivial changes (typo fixes, punctuation). Focus on patterns:
- Did I cut filler or throat-clearing?
- Did I make something more specific or concrete?
- Did I remove hedging or qualifiers?
- Did I restructure (for example, lead with the point instead of building up to it)?
- Did I change the register (formal to casual, or the reverse)?
- Did I cut entire sections?

## Step 3: Save

Append each correction to the project's voice notes file, in the format below. The project keeps its voice notes in one file. Use that file. If none exists yet, create it where the project keeps such notes.

```
- "original phrasing" -> "my version" -> Lesson learned
```

Group related corrections if they reflect the same underlying lesson.

## Step 4: Confirm

Tell me how many corrections were logged and what patterns you see. Keep it to 3 or 4 lines.

## Rules

- Be specific. "Write better" is useless. "Do not hedge with 'I think' or 'it seems'. State it directly" is useful.
- Do not log more than 5 corrections per session. Pick the most instructive ones.
- If this is the first run, create the voice notes file.
