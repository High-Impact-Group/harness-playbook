# Routines

A routine is a reusable instruction you give an AI session or a person to follow. Each file here is plain text. Paste it into your tool as a saved prompt, a custom command or a runbook, whatever your tool calls it.

| Routine | Use it to |
|---|---|
| `decide.md` | Interview the owner about the decisions only they can make, in the chat |
| `decision-brief.md` | Put those decisions in one document the owner can approve and comment on |
| `plan.md` | Write a plan before any code |
| `gate.md` | Run a full quality gate over the current changes |
| `session-start.md` | Start a working session with the right context |
| `session-end.md` | End a session and leave notes for the next one |
